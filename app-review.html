sjTracker Sample Files

Downloadable sample videos and instructions for testing sjTracker. These files are provided for Apple App Review and future update reviews.

How to test sjTracker

  1. Download one of the sample videos below.
  2. Open sjTracker.
  3. Choose Video or drag the downloaded video into the app.
  4. Choose an output folder.
  5. Keep Export CSV enabled.
  6. Run tracking.
  7. Confirm that sjTracker creates a CSV file in the selected output folder.

Notes for App Review

sjTracker processes the selected video locally on the Mac. No video, pose data, or CSV file is uploaded or transmitted.

Processing time depends on the Mac model and the length of the video. The short sample is provided so the main workflow can be verified quickly.
